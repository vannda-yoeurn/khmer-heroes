# វីរជនខ្មែរ ៖ ដំណើរស្វែងរកស្រូវពូជ

ហ្គេមផ្សងព្រេង 3D (Unity 6) ដែលតួអង្គស្លៀកពាក់បែបខ្មែរបុរាណ — សំពត់ចងក្បិន សំពត់ហូល ក្រមា និងគ្រឿងអលង្ការមាស។

## សាច់រឿង
ក្រុមចោរព្រៃបានលួចកញ្ជើស្រូវពូជរបស់ភូមិ មុនរដូវវស្សា។ វីរជនបួននាក់ចេញដំណើរកាត់ ៥ តំបន់ ដើម្បីយកវាមកវិញ៖

| តំបន់ | អ្វីដែលត្រូវធ្វើ |
|---|---|
| ១. ភូមិជើងភ្នំ | ជួបតាមាស ហើយឆ្លើយសំណួររបស់ពូជ័យ (ត្រូវ ២/៣) ដើម្បីបើកទ្វារ |
| ២. វាលស្រែ និងព្រៃឫស្សី | ប្រយុទ្ធជ្រូកព្រៃ · រុញថ្មពីរដុំលើបន្ទះភ្លឺ |
| ៣. ភ្នំខ្លា | កម្ចាត់ខ្លា · អុជចន្លុះតាមលំដាប់ពណ៌ · (ជម្រើស) សំណួររបស់តាព្រាន |
| ៤. ទន្លេក្រពើ | ទាញដងទាញពីរ ដើម្បីបន្ទាបស្ពាន · (ជម្រើស) សំណួររបស់យាយស |
| ៥. ជំរុំចោរព្រៃ | ប្រយុទ្ធមេចោរដៃដែក (Boss) · យកកញ្ជើស្រូវពូជ |

## វីរជនទាំងបួន (ប្ដូរបានគ្រប់ពេលដោយចុច ១ ២ ៣ ៤)
- **សុខា** — អ្នកដាវ · ក្បាច់វិលដាវ
- **ចន្ទា** — អ្នកបាញ់ធ្នូ · ព្រួញបី
- **ដារ៉ា** — អ្នកគុនល្បុក្កតោ (ដំបង) · ក្បាច់បោកដី
- **ស្រីពៅ** — អ្នកកាំបិតភ្លោះ · ក្បាច់ផ្លេកបន្ទោរ

## សត្វជំនិះ និងការប្រណាំង (កំប្លែងៗ)
នៅក្រោលសត្វក្នុងភូមិ មានសត្វជំនិះ ៦ ប្រភេទ ដែលមានភ្នែកធំៗ និងសំឡេងកំប្លែង៖ **សេះ** (លឿន), **ដំរី** (បុកសត្រូវហោះឆ្ងាយ), **ខ្លាស្លូត**, **ឆ្មាយក្ស** (លោតខ្ពស់ជាងគេ), **ឆ្កែ** (លឿនជាងគេ) និង **ក្របី** (ស្នែងធំ)។
- F ជិះ · R ចុះ · Shift ស្ទុះ · Space លោត · រត់បុកសត្រូវឲ្យហោះវិលៗ
- ជិះចេញទៅប្រយុទ្ធនៅគ្រប់តំបន់បាន

**ការប្រណាំងសត្វ**៖ និយាយជាមួយ **ពូចាន់** ក្នុងភូមិ ដើម្បីប្រណាំង ២ ជុំ ជាមួយ ស្រីល័ក្ខ (ឆ្មា), ពូធំ (ដំរី) និងអាតូច (ឆ្កែ)។ ប្រយ័ត្នសំបកចេក (រអិលវិល) ភក់ (យឺត) ហើយរើសអំពៅដើម្បីលឿន។ លេខ ១ បាន ៦០ កាក់មាស!

## កោះឧបសគ្គ · លេងច្រើននាក់ (រហូតដល់ ៤ នាក់)
ចុច **«កោះឧបសគ្គ · លេងច្រើននាក់»** នៅម៉ឺនុយដើម។ ផ្លូវឧបសគ្គមាន៖ ក្បូនឫស្សីអណ្ដែត · ដុំឈើយោល · ដងបង្វិល · ក្បូនរំកិល · ទ្វារសាមគ្គី · ក្ដារស្រុត · ស្គរលោត · ផ្លែដូងរមៀល → ពានមាស។
- **ម្នាក់ឯង** — ប្រកួតពេលវេលាខ្លួនឯង (គ្មានអ៊ីនធឺណិត)
- **សាមគ្គី** — ជួយគ្នា។ ទ្វារបើកតែពេលមានអ្នកឈរលើបន្ទះខៀវទាំងពីរព្រមគ្នា ហើយបើនរណាម្នាក់ធ្លាក់ទឹក នឹងត្រឡប់ទៅចំណុចដែលក្រុមទៅដល់ឆ្ងាយជាងគេ
- **ប្រកួត** — ប្រណាំងទៅពានមាស អាចរុញគូប្រកួត (J/កណ្ដុរឆ្វេង)
- ពាក្យកំប្លែងលើក្បាល៖ ៥ «ហាហា!» · ៦ «មកជួយផង!» · ៧ «ទៅមុខ!» · ៨ «សុំទោស!»

**ការភ្ជាប់៖**
- **Wi-Fi តែមួយ (LAN)** — ម្នាក់ចុច «បង្កើត LAN» ហើយអ្នកផ្សេងវាយ IP ដែលបង្ហាញ រួចចុច «ចូលតាម IP»
- **តាមអ៊ីនធឺណិត (លេខកូដបន្ទប់)** — ប្រើ Unity Relay។ ត្រូវភ្ជាប់គម្រោងទៅ Unity Cloud ម្ដងសិន៖ *Edit › Project Settings › Services* → Link (ឥតគិតថ្លៃសម្រាប់ចំនួនអ្នកលេងតិច)
- ម៉ឺនុយ **KhmerHeroes › Build Windows (.exe)** បង្កើតហ្គេមសម្រាប់ចែកឲ្យមិត្តភក្ដិ (ក្នុងថត `Builds/Windows`)

## ឧបសគ្គក្នុងដំណើររឿង
- ដុំឈើយោលកាត់ផ្លូវនៅព្រៃឫស្សី · ដុំថ្មរមៀលចុះពីភ្នំខ្លា (ចុច Shift គេច!)

## របៀបបើក
1. បើក **Unity Hub** → **Add** → **Add project from disk** → ជ្រើសថត `KhmerHeroes`
2. បើកដោយ Unity **6000.6.9f1** (ឬ Unity 6 ថ្មីជាងនេះ)
3. រង់ចាំ Unity រៀបចំគម្រោងលើកដំបូង (ប្រហែល ២–៥ នាទី)។ គម្រោងនឹងបង្កើត `Assets/Scenes/Main.unity` ដោយខ្លួនឯង
4. ចុច **Play** ▶

> ពិភពលោកទាំងមូល តួអង្គ សត្វ សំឡេង និងភ្លេងបែបខ្មែរ (រនាត ស្គរ ឈិង) ត្រូវបានបង្កើតដោយកូដ — មិនត្រូវការទាញយកអ្វីបន្ថែមទេ។
