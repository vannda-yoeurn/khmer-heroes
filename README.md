# វីរជនខ្មែរ ៖ ដំណើរស្វែងរកស្រូវពូជ

ហ្គេមផ្សងព្រេង 3D (Unity 6) ដែលតួអង្គស្លៀកពាក់បែបខ្មែរបុរាណ — សំពត់ចងក្បិន សំពត់ហូល ក្រមា និងគ្រឿងអលង្ការមាស។

## សាច់រឿង
ក្រុមចោរព្រៃបានលួចកញ្ជើស្រូវពូជរបស់ភូមិ មុនរដូវវស្សា។ វីរជនបួននាក់ចេញដំណើរកាត់ ៥ តំបន់ ដើម្បីយកវាមកវិញ៖

| តំបន់ | អ្វីដែលត្រូវធ្វើ |
|---|---|
| ១. ភូមិជើងភ្នំ | ជួបតាមាស ហើយឆ្លើយសំណួររបស់ពូជ័យ (ត្រូវ ២/៣) ដើម្បីបើកទ្វារ |
| ២. វាលស្រែ និងព្រៃឫស្សី | ប្រយុទ្ធជ្រូកព្រៃ · រុញថ្មពីរដុំលើបន្ទះភ្លឺ |
| ៣. ភ្នំខ្លា | កម្ចាត់ខ្លា · អុជចន្លុះតាមលំដាប់ពណ៌ · (ជម្រើស) សំណួររបស់តាព្រាន |
| ៤. ទន្លេក្រពើ | ទាញដងទាញពីរ ដើម្បីបន្ទាបស្ពាន · (ជម្រើស) សំណួររបស់យាយស |
| ៥. ជំរុំចោរព្រៃ | ប្រយុទ្ធមេចោរដៃដែក (Boss) · យកកញ្ជើស្រូវពូជ |

## វីរជនទាំងបួន (ប្ដូរបានគ្រប់ពេលដោយចុច ១ ២ ៣ ៤)
- **សុខា** — អ្នកដាវ · ក្បាច់វិលដាវ
- **ចន្ទា** — អ្នកបាញ់ធ្នូ · ព្រួញបី
- **ដារ៉ា** — អ្នកគុនល្បុក្កតោ (ដំបង) · ក្បាច់បោកដី
- **ស្រីពៅ** — អ្នកកាំបិតភ្លោះ · ក្បាច់ផ្លេកបន្ទោរ

## របៀបបើក
1. បើក **Unity Hub** → **Add** → **Add project from disk** → ជ្រើសថត `KhmerHeroes`
2. បើកដោយ Unity **6000.6.9f1** (ឬ Unity 6 ថ្មីជាងនេះ)
3. រង់ចាំ Unity រៀបចំគម្រោងលើកដំបូង (ប្រហែល ២–៥ នាទី)។ គម្រោងនឹងបង្កើត `Assets/Scenes/Main.unity` ដោយខ្លួនឯង
4. ចុច **Play** ▶

> ពិភពលោកទាំងមូល តួអង្គ សត្វ សំឡេង និងភ្លេងបែបខ្មែរ (រនាត ស្គរ ឈិង) ត្រូវបានបង្កើតដោយកូដ — មិនត្រូវការទាញយកអ្វីបន្ថែមទេ។
